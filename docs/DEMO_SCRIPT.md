# 3-minute demo script

**0:00–0:20 — Problem**  
E-waste hit 62 Mt in 2022; most value is shredded. Show stock photo of e-waste + stat overlay.

**0:20–0:40 — Solution**  
Open RE:GENESIS UI. “Retired Dell PowerEdge R740.” Upload interior photo or select model.

**0:40–1:00 — Detection**  
Bounding boxes appear. Voice: “SageMaker YOLO identifies GPUs, RAM, SSDs.” If fallback: “Catalog-assisted mode when vision is uncertain.”

**1:00–1:20 — Plan**  
Scroll disassembly timeline. Highlight RVS: “Highest reuse value and lowest risk first.” Show completeness audit warnings if any.

**1:20–1:40 — Diagnostics**  
Progress through simulated tests. One GPU pass, one RAM pass.

**1:40–2:00 — Passport**  
Open passport card. Click **Verify** — KMS valid. “Second-Life Passport for reuse marketplaces.”

**2:00–2:30 — Impact**  
Impact panel: kg diverted, CO₂e avoided vs shred baseline.

**2:30–3:00 — AWS scale**  
Step Functions execution screenshot. “Serverless pipeline for every AWS re:Cycle-style hub.” End card: team + hackathon.
